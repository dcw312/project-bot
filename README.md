# project-bot

Project-Bot is a chatbot designed to assist with project management tasks, such as tracking progress, managing tasks, and facilitating team communication. It integrates with popular project management tools and provides a conversational interface for users to interact with their projects efficiently.

## Setup

Create a virtual environment and install the required dependencies:

```bash
python3 -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`
pip install -r requirements.txt
```
